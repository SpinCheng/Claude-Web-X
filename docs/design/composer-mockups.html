方案 A · 隐形式

输入即主角。元信息全部上收进顶部一条静默遥测带；发送是悬挂右下角的珊瑚橘大圆钮（52px 触达友好）。视觉最干净，最像"正经聊天工具"。

方案 B · 指挥台 推荐

延续"远程监控台"产品气质：等宽遥测条常显全部数据；输入行带终端提示符 > 与转录机器文本同语言；发送/停止常驻双钮不再互相顶替；运行时遥测条下方一根珊瑚橘呼吸线是全 UI 唯一动效心跳。

方案 C · 抽屉式

阅读优先。静息态只剩一条 46px 胶囊，整屏让给转录；点按/键盘弹出/运行中自动展开为完整 dock。屏幕利用率最高，但有状态切换学习成本，实现也最复杂。
